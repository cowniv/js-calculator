# 06 · Calculator

**Roadmap stage:** Phase 3 – JavaScript Fundamentals · August 2024

My first real JavaScript app: a calculator with an iOS-inspired look.

### Features
- Chained operations (`2 + 3 × 4 =` evaluates left to right)
- Delete, clear and percent
- Divide-by-zero handling
- Fixes floating-point noise (`0.1 + 0.2` shows `0.3`)
- Full keyboard support

### What I practiced
- DOM selection and `textContent`
- Event delegation with `closest()`
- `data-*` attributes
- Keeping app state in variables
- `switch` statements
